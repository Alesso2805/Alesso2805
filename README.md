# Alessandro David Polanco

Backend engineer in Lima, Peru. I mostly write Python (FastAPI, SQLAlchemy) and spend a lot of my time on the data layer: queries, migrations and the tests around them.

At [White Lion Technology](https://www.linkedin.com/in/alessandro-david-polanco-71657421b/) I work on workforce-management software for mining and construction: an LMS, a training platform and an access-control system, with FastAPI and SQL Server on the backend and React on the front. I studied Software Engineering at UPC, and my thesis turned into a first-author paper in IEEE Xplore.

## Projects

**[SentinelAPI](https://github.com/Alesso2805/sentinelapi)**: threat-detection middleware for FastAPI. Rate limiting, credential-stuffing detection per account, single-use refresh tokens and an audit trail, written as pure ASGI with Redis and PostgreSQL. Published on PyPI as `fastapi-sentinel`. [Live demo](https://sentinelaapi.duckdns.org)

**[Willay](https://github.com/Alesso2805/willay)**: early-warning system for floods and debris flows. Stations send readings, rules open incidents, and alerts keep escalating until someone acknowledges them. Async FastAPI, PostgreSQL as the queue, Keycloak. [Live demo](https://willay.duckdns.org)

**[VeriLedger](https://github.com/Alesso2805/veriledger-api)**: a small verifiable ledger with Ed25519-signed transfers, a SHA-256 hash chain and proof of work. FastAPI, SQLAlchemy 2, PostgreSQL, React. [Live demo](https://veriledger.duckdns.org)

**[¿EsFake?](https://github.com/Alesso2805/esfake)**: a scam-message checker for Peru (web and WhatsApp). Work in progress.
